## Guidelines
- Always write idiomatic Rust code.
- Always write tests first. Use TDD.
- Always add rustdoc /// comments to all public functions and structs.
- Use Object-oriented programming. Create structs for program abstractions.
- Use Design patterns when needed.
- Use async/await and tokio for I/O operations.
- Use multithreading for CPU-bound tasks when needed.
- Use industry best practices for all code.
- Use less computational-intensive algorithms in terms of Big O when possible.
- Use dependency injection for managing dependencies.
- Use anyhow for error handling.
- Use clap for command-line arguments.
- Use a linter (Clippy) for checking code style.
- Use a formatter (Rustfmt) for formatting code.

## Workflow

- Always write tests first when implementing features or fixing bugs (TDD).
- Before committing, ensure docs and `README.md` are updated.
